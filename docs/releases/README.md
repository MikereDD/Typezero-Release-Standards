# Standards Release Notes

Release notes for versioned Typezer∅ Release Standards releases belong in this directory.

The repository is currently pre-v1.0 and has no stable standards release yet. When the first standards release is tagged, add a corresponding document such as:

```text
v1.0.md
```

Standards release notes should call out manifest-schema changes, updater-protocol changes, migration requirements, newly mandatory security rules, and template compatibility implications.
